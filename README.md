O projeto tem como objetivo controlar:

- compras;
- estoque;

- remessas;
- vendas;

Tecnologias e conceitos utilizados:

- Java;
- Java Swing;
- SQLite;
- JDBC;
- DAO;
- programação orientada a objetos;
- arquitetura em camadas;
- regras de negócio.
